# whereismyspace v1.0.0

First stable release. The maintainer reports several months of stable use of
the development binary. These release assets are new builds of that source;
that usage history does not constitute testing on every target platform.

## Included

- Allocated disk usage on Unix, filesystem boundary detection and hardlink deduplication.
- Directory lists, trees, largest-file lists and JSON output.
- OS-aware exclusions and configurable scan concurrency.
- Cached scans with subtree lookup, expiry, refresh and option matching.
- MIT-licensed source and archives for Linux amd64/arm64, macOS amd64/arm64
  and Windows amd64. Every archive contains the binary, documentation and licenses.
- `SHA256SUMS` and `BUILDINFO.json` with source hashes, commit, compiler and flags.

## Validation and limits

Release preparation runs the existing format, vet and race checks and exercises
the native Linux amd64 binary's version, JSON output, cache, subtree lookup and
largest-file mode on an isolated fixture. Other targets are cross-compiled;
runtime testing on macOS, Windows and ARM64 remains outstanding.

Windows reports estimated sizes and lacks Unix mount detection and hardlink
deduplication. macOS and Windows binaries are unsigned. Scan totals may differ
from `df`; inaccessible files and exclusions affect completeness. Cached results
can be stale: use `--refresh` or `--no-cache` when checking current usage.
